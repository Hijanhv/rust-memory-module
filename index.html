Module 1 · Memory

Rust memory, one small step at a time

Where does your data actually live when a Rust program runs? And what goes wrong when the rules are broken? This site walks you through it slowly, with pictures you can click through.

How to use this site
  1. New to Rust? Start with the Rust Book essentials (0.1 to 0.5). They teach the exact Rust Book chapters Lessons 1 and 2 depend on. Already comfortable? Jump to 1.1.
  2. Go in order. Every page builds on the one before it.
  3. Each lesson starts with a one-sentence summary. If you only remember one thing, remember that.
  4. Click Next ▶ on the diagrams (or use your arrow keys) to watch memory change line by line.
  5. Answer the questions at the bottom before opening the answer. Then mark the page done.
  6. Finish with the Mastery test. Score 90% and you own Lessons 1 and 2.

Every lesson also has a matching program in the lab/ folder of the GitHub repo. You only need normal Rust (cargo) to run them. No extra tools.
